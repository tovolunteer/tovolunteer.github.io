# data/geo
- `fsa.json`: Ontario FSA (first 3 chars of postal code) centroids [lat, lng]. Source: GeoNames postal codes CA.zip (https://download.geonames.org/export/zip/), CC BY 4.0, downloaded 2026-10-13.
- `places.json`: id -> {lat, lng, query} geocoded at build time (OpenStreetMap Nominatim, ODbL).
