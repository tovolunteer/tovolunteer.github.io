# Toronto Volunteer Hub

Volunteer opportunities around Toronto — tree planting, environmental stewardship and food banks — in one place.
Site: https://tovolunteer.github.io/

- **Happening Soon**: upcoming events scraped twice a day from public pages (TRCA, LEAF). Always confirm on the official page.
- **Plan Ahead**: ongoing programs and food banks, maintained by hand in `data/manual/*.yaml` (each entry has a `last_verified` date and sources).

Corrections welcome via issues or pull requests.

Data credits: postal code centroids © GeoNames (CC BY 4.0); map data © OpenStreetMap contributors (ODbL).
